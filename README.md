# See What's Working

**Open source SaaS revenue intelligence.** Discover what's already making money before you build.

See What's Working is a free, open source tool that estimates MRR/ARR for SaaS companies using publicly available data — so founders, indie hackers, and dev studios can validate ideas based on real market signals instead of guesswork.

## Why This Exists

Every SaaS founder has the same problem: you spend months building something, only to discover nobody wants it. Paid intelligence tools solve this by showing you what's already working — but they charge $50-200/mo for data that's mostly derived from public sources.

This project makes that intelligence free and transparent. The estimation methodology is open, the data pipeline is auditable, and anyone can contribute improvements.

## What It Does

- **Revenue Estimation** — Estimates MRR for SaaS companies using public signals (web traffic, pricing pages, employee count, ad spend indicators, tech stack, review volume)
- **SaaS Directory** — Browse and search a growing database of SaaS products with estimated revenue, category, and growth trends
- **Niche Discovery** — Filter by category, revenue range, and growth rate to find proven niches worth entering
